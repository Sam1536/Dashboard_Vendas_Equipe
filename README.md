# 🏆 Dashboard de Vendas em Equipe | Power BI

Dashboard interativo para acompanhar o desempenho de uma equipe de vendas: **faturamento**, **lucro** e **quantidade vendida**, com ranking de vendedores, evolução ao longo do tempo e análise das formas de pagamento.

## ✨ Recursos

- Indicadores de **Total Faturamento**, **Total Lucro** e **Quantidade Vendida**
- Ranking de vendedores por faturamento, com a foto de cada um
- Evolução do faturamento e da quantidade vendida por data
- Distribuição das vendas por forma de pagamento
- Destaques de vendedor e de produto

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query · Visuais personalizados (grade de imagens)

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**.
